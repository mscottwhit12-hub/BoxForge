BoxForge v0.2.6: dieline generator for cardboard and laser-cut boxes.

**Styles:** Slotted Box (RSC), Lid & Base, Diagonal Insert, Cross / grid divider, Slot-fit test.

**This release**
- Panel labels and dimension callouts on the dieline; click a callout to change the matching size.
- Faster, steadier 3-D fold preview (no camera drift while folding).
- Fixes from an independent bug audit: Lid & Base sizes, outer-mode box height, tolerance and glue-flap checks, comma
  decimals, unsaved-project prompts, high-DPI layout, closed SVG outlines, and more.
- Project files, recent list, screen scaling and Mac menu support.

**Downloads**
- `BoxForge-windows.zip`: unzip and run `BoxForge.exe`.
- `BoxForge-macos.zip`: unzip, then right-click `BoxForge.app` and choose Open the first time (unsigned app).

Windows and macOS builds are made by GitHub Actions and have not been tested on real machines by the author yet.
